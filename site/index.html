See sample sizes, exact scores, and claim limits

Same-WAV local benchmark. Every tested local engine hears the same audio. References use Gemini-cross-checked gold.

English parity (n=152, updated 2026-08-15). Two real-speech corpora: 79 longer dictations and 73 short dictations. RambleFix and Handy 0.9.4 had identical meaning and term scores on 152/152 clips.

Speed boundary. Warm decode p50 was 0.456s vs 0.462s on the longer set, and 0.209s vs 0.219s on the short set. Confidence intervals span zero, so this is parity, not a speed win. App release-to-paste was not measured symmetrically.

Claim boundary. The evidence supports parity with the strongest tested local English path. Paid cloud tools have not yet been run on a clean same-audio test.

Hindi+English beta n=13. RambleFix 88.5% vs 66.1-70.2% meaning kept for tested local general engines; terms 70.1%.

Structure gate: 0 unsafe accepted updates. Cleanup accepted 152 edits with 0 meaning changes.

Hindi+English keeps more meaning than the tested local alternatives. Hindi+English ships as experimental.

Wispr Flow comparisons remain directional: we have not run cloud tools on the same audio, so this is not a head-to-head superiority claim.
