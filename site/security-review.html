Security review notes

Built to be easy to review before work use.

RambleFix is designed as a local dictation app: voice capture, transcription, logs, and light structure stay on the Mac unless the user explicitly exports diagnostics.

Permissions

Microphone for voice. Accessibility/Input Monitoring for hotkey and paste. No Screen Recording in V0.

On-device only

All transcription runs locally on the Mac. Local helper servers bind to loopback (127.0.0.1) only. There is no cloud transcription, no account, and no login.

Your voice & text never leave

Audio and everything you dictate stay on the Mac and are never uploaded. Audio is deleted right after transcription; a clip from a failed run is held locally up to 48h so you can recover it, then auto-deleted.

No model training on your data

Your audio and transcripts are never used to train or improve any model. The speech models are fixed and bundled in the app — nothing you say is sent anywhere for training.

Optional anonymous usage stats

Off with one click, and disable-able entirely for a managed pilot. When on, it sends counts and timings only — app version, which engine ran, how long it took, success/no-speech — never any audio or text.

Out of scope

No meeting recording, no file uploads, no SaaS connectors, no browser extension, no shared or team accounts, no autonomous actions. Manual dictation of the user's own voice, reviewed by the user before use.

Release integrity

Public builds must be Developer ID signed, notarized, stapled, and published with SHA-256 checksums.

Before public release, RambleFix also needs the signed DMG, notary profile, embedded runtime audit, dependency/SBOM review, third-party model notices, and a clean-machine install test.
